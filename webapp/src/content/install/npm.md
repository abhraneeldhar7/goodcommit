Requires [Node.js](https://nodejs.org/) (v18+).

```bash
npm install -g xommit
```

This adds the `xommit` command to your PATH globally.

If you get a permission error, use:

```bash
sudo npm install -g xommit
```

Or fix your npm permissions: [docs.npmjs.com/resolving-eacces-permissions-errors](https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally)

Verify it worked:

```bash
xommit --version
```
