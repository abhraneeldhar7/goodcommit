You need to have [Node.js](https://nodejs.org/) installed.

```terminal
npm install -g @abhraneeldhar7/xommit
```

This adds the `xommit` command to your PATH globally. Package page: [@abhraneeldhar7/xommit on npm](https://www.npmjs.com/package/@abhraneeldhar7/xommit)

If you get a permission error, use:

```cmd
sudo npm install -g @abhraneeldhar7/xommit
```

Or fix your npm permissions: [docs.npmjs.com/resolving-eacces-permissions-errors](https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally)

Verify it worked:

```cmd
xommit --version
```
